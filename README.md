A tiny Python program that writes one funny "famous last words" epitaph to `/output/entry.txt`: *"They charge by the letter, so this is all I get: I told you the mushrooms were fine."* — a last-words joke where the cost of carving letters explains the brevity, and the cause of death is the punchline.

## Run it

```sh
python3 main.py
```
